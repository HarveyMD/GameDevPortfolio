- **Assets** — PNG/GIF screenshots, MP4 video clips

## Setup

Clone the repo and open `index.html` in a browser — no build step required.

```bash
git https://github.com/HarveyMD/GameDevPortfolio.git
cd GameDevPortfolio
start index.html
```
